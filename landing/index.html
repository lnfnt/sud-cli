sud-cli// юридический экзоскелет в терминале

AGPL-3.0 v2.9.0 fail-closed детерминированный вывод изолированное хранилище Python

CLI-экзоскелет для юридической работы: судебные дела и события, процессуальные сроки, госпошлины по НК РФ, проценты по ст. 395 и 317.1 ГК РФ, производственные календари с региональными праздниками, реквизиты платежей (КБК). Каждый расчёт исполняется строго по утверждённой спецификации правил: вызов вне спецификации отклоняется с явным статусом вместо тихого нуля на выходе.

Быстрый старт

# диагностика окружения и хранилища
python -m pip install -e .
sud-cli doctor

# дела и события: импорт, карточка, поиск
sud-cli court import fixtures/cases.json
sud-cli court case CASE-0001
sud-cli court search встречное требование --since 2026-01-01 --until 2026-12-31 --limit 10

# нормативные документы: поиск и сравнение редакций
sud-cli npa search договор
sud-cli npa compare --id NPA-0001 --edition1 v1 --edition2 v2

# официальные публикации: только метаданные
sud-cli law search "о банкротстве"
sud-cli law search --number "12345"

Дела и документы

Версионированная схема

cases/events — нормализованная карточка дела и детерминированно упорядоченная лента событий: заседания, определения, итоги.

Локальный поиск

Свободный полнотекстовый поиск по импортированным делам с датовыми границами и лимитом результата. Тела документов не возвращаются — только метаданные и события.

Редакции НПА

npa compare — сравнение версий документа по фиксациям; npa search — поиск по реестру. Без живых источников.

Официальные публикации

law search — один явный HTTPS-запрос к документированному endpoint официального опубликования, возвращает только метаданные.

Сроки и календарь

Сроки — самая дорогая ошибка в процессе. Расчёт ведётся до секунды местного времени суда, с учётом переносов выходных и региональных праздников.

ВозможностьДетали
Региональные праздники--region (например, 16 — Татарстан, 02 — Башкортостан): региональные нормы накладываются на федеральный производственный календарь.
Часовой пояс суда--tz (по умолчанию Europe/Moscow): сроки до 23:59:59 местного времени суда (ч. 6 ст. 114 АПК РФ).
Проверка календаряsud-cli calendar check — покрытие переносов указами и годы действия календаря.
Финансовый контурПроценты по ст. 395 / 317.1 ГК РФ через меняющиеся ключевые ставки ЦБ, с учётом частичных платежей и судебных расходов.
sud-cli interest --principal 1500000 --start 2025-06-01 --end 2026-10-01 \
  --payments "2025-12-15:500000,2026-03-01:300000" --calc-fee

Госпошлины и платежи

КомандаЧто делает
sud-cli feesГоспошлина по утверждённой спецификации. Банкротные пошлины 259-ФЗ: 100 000 ₽ (юрлицо), 10 000 ₽ (физлицо), прогрессивные вилки требований кредиторов (ст. 333.21 п. 1 пп. 5 НК РФ). Вызовы вне спецификации — UNSUPPORTED, не догадка.
sud-cli paymentРеквизиты платежа: КБК и назначение платежа для арбитражных судов, судов общей юрисдикции и КАС.
sud-cli deferralХодатайство об отсрочке/рассрочке (ст. 333.41 НК РФ, ст. 102 АПК РФ) с обязательным чек-листом банковских и налоговых справок.
sud-cli fees --jurisdiction arbitration --kind bankruptcy_petition --entity individual
sud-cli payment --jurisdiction arbitration --court "АС Московского округа" \
  --defendant "ООО Ромашка" --amount 250000

Гарантии контура

Fail-closed

Расчёты исполняются строго по утверждённой спецификации правил. Вне спецификации — явный UNSUPPORTED/MISSING, а не пустой успех.

Изолированное хранилище

Всё локальное состояние — в каталоге, принадлежащем sud-cli (~/.local/share/sud-cli; переопределяется SUD_CLI_STATE_DIR или --state-dir).

Честная деградация

Ошибки — ненулевой код с явным сообщением. Никаких «пустых успехов»: недоступный источник помечен недоступным, не подменяется молчанием.

Синтетические фикстуры

Импорт и поиск проверяются на синтетических данных: ни реальных номеров дел, ни учётных данных, ни подлинных документов в тестах.

Без живого доступа к порталам

Картотеки и порталы судов напрямую не опрашиваются: работа — с импортированными материалами и ограниченными метаданными официального опубликования.

Эргономика

--json принимается в любой позиции любой подкоманды — машинный разбор не зависит от порядка аргументов.

Конфигурация

Переменная / флагНазначение
SUD_CLI_STATE_DIRКаталог состояния; по умолчанию ~/.local/share/sud-cli.
--state-dirТо же на уровне отдельного вызова.
--jsonМашиночитаемый вывод; допустим в любой позиции.

Область применения: российская юрисдикция. Расчёты носят вспомогательный характер и не заменяют проверку юристом.
