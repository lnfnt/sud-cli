# Формат судебного .docx (sud-cli draft)

Офисный стандарт оформления процессуальных документов, собираемых
`sud-cli draft` (модуль `sud_cli/drafter.py`, `build_docx`).

## Шрифт и абзац

- Шрифт: Times New Roman, 14 pt (для латиницы/кириллицы/восточноазиатского
  набора — одинаково через `w:rFonts`).
- Межстрочный интервал: полуторный (1.5).
- Красная строка: 1.25 см (только у «текстовых» блоков: фабула, правовое
  обоснование, расчет, просительная часть; не у реквизитов и приложений).
- Выравнивание по ширине (justify) у текстовых блоков; заголовок — по центру.

## Поля страницы

Порядок сторон: **левое / правое / верхнее / нижнее**.

| Поле    | Значение |
|---------|----------|
| левое   | 3.0 см   |
| правое  | 1.5 см   |
| верхнее | 2.0 см   |
| нижнее  | 2.0 см   |

Левое поле увеличено для подшивки документа к материалам дела, правое
минимально допустимое — максимум ширины текстового поля на А4.

## Структура документа (порядок блоков)

1. `header` — «В <наименование суда>», слева.
2. `req` — реквизиты сторон (истец/ответчик или заявитель/ответчик,
   представитель по доверенности, дело №), с отступом 9 см слева.
3. `title` — заголовок документа (центр, полужирный; override полем `title`).
4. `body` — фабула/обстоятельства (override: `basis` строкой или списком
   абзацев).
5. `law` — нормативное обоснование (override полем `normative`).
6. `calc` — расчет взыскиваемой суммы / госпошлины.
7. `petitum` — «На основании изложенного ПРОШУ: …».
8. `appendix` — «Приложения: …» (ст. 132 ГПК РФ; override полем `appendix`).
9. `signature` — дата и подписи, **вправо**: ««___» __________ 20__ г.»
   и строка «____________ / Подписант /» на каждого подписанта
   (override полем `signature`; по умолчанию — истец/заявитель и
   представитель по доверенности).

## Метаданные

- Автор документа: `sud-cli` (`DOCX_AUTHOR`).
- Буква «ё» вычищается в описательной части (`_clean_yo`), официальные
  реквизиты сторон и подписанты не изменяются.
- Лимит длины текстового поля: `MAX_FIELD_LENGTH = 10000` символов
  (на поле, включая суммарно для списков).
