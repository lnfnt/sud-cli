# Корпус Пленума/Президиума ВС для `sud-cli plenum search`

Локальный RAG-поиск (гибрид BM25 + векторный, RRF) по постановлениям
Пленума ВС РФ. Ридер — `sud_cli/plenum_rag.py` (команда `sud-cli plenum
search`, MCP-тул `sud_cli_plenum_search`). Билдер — `scripts/build_plenum_corpus.py`.

## Политика распространения (решение владельца 07.11.2026)

База корпуса в публичный контур **не выкладывается**: RAG — не бесплатный
дарок, каждый пользователь собирает себе сам. В репозитории живут только
ридер и билдер. Скрипт выгрузки корпуса с www.vsrf.ru (1521 постановление)
держится вне репо (`datasets/vsrf-plenum-1521/fetch_plenum.py`).

## Сборка базы

```bash
python3 scripts/build_plenum_corpus.py \
    --src /path/to/vsrf-plenum-1521 \
    --embed-url http://<ollama>:11434/api/embeddings \
    --out ~/.sud-cli/plenum-corpus.db
```

- Источник: каталог с `meta/index.json`, `texts/*.html`, `files/*.{docx,html}`
  (формат выгрузки fetch_plenum.py). docx предпочитается html.
- Чанкование: по пунктам («N.» / «N)»), вводная часть — отдельный чанк,
  длинные пункты режутся на части по 3000 знаков.
- Эмбеддинги: bge-m3 через ollama `/api/embed`, батчами по 32.
  Переданный `--embed-url` с `/api/embeddings` автоматически приводится
  к батчевому `/api/embed`.
- Схема sqlite повторяет фикстуры тестов: `documents`, `chunks`,
  `chunks_fts` (FTS5, rowid выровнен с `chunks.rowid`), `chunk_embeddings`
  (float32 blob).

## Переменные окружения (ридер)

- `SUD_PLENUM_DB` — путь к базе (дефолт `~/.sud-cli/plenum-corpus.db`).
- `SUD_PLENUM_EMBED_URL` — эндпоинт эмбеддинга запроса
  (дефолт `http://127.0.0.1:11434/api/embeddings`).

## Проверено 07.11.2026 (the project-контур)

Сборка из 1006 документов (1520 кандидатов минус безтекстовые): 13 786
чанков, 13 786 эмбеддингов, 0 отказов, ~18 минут. Запросы «снижение
неустойки ст. 333 ГК» и «исковая давность течение срока» дают точные
попадания (п. 65 Пленума № 2 от 29.01.2015; п. 25, 57 смежных Пленумов),
латентность ~5 с.

## Хвосты

1. Дефолт эмбеддера ридера — `127.0.0.1:11434`; в the project-контуре ollama на
   `198.51.100.1:11434` — без `SUD_PLENUM_EMBED_URL` поиск деградирует
   до BM25-only.
2. Все документы помечаются `status='active'`; устаревшие редакции и
   отменённые пункты база не различает (ридер умеет фильтровать, данных
   для фильтра нет).
3. Негативный фильтр корпуса в ридере (устаревшие пункты) опирается на
   поле, которое билдер не заполняет, — фактически негативный пул пуст.
4. ВАС-корпус (Пленумы ВАС до 2014) в поиск не входит — только ВС РФ.
